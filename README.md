# Pickleball 98

A Windows 98-style 3D pickleball game: quick matches against the computer or online, My Park at
real venues from OpenStreetMap, an open world to explore, a real-life scorekeeper (Real Games),
weekly tournaments, Twin Replay and Live Broadcast.

Originally part of [98ish](https://github.com/brandontaylor156/98ish).

- `npm install && npm start` runs the server (port 8000).
- `cd client && npm install && npm run dev` runs the site.

See `CLAUDE.md` for the layout and `docs/` for each area.
